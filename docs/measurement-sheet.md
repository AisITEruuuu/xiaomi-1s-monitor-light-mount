# 通用 VESA 挂灯适配测量表

本表只记录**挂灯原装底座与承托片之间**的接口尺寸。VESA 侧采用固定标准接口，不再逐台测量显示器。

## VESA 固定规格

以下内容属于产品规格，不需要填写测量表：

- VESA 孔距：同时支持 `75 × 75 mm` 和 `100 × 100 mm`
- 通孔：`Ø4.5 mm`
- 螺丝：M4
- 转接板厚度：`6 mm`
- 悬臂高度：应提供上下调节范围，用来适配显示器上沿到 VESA 中心的不同距离
- VESA 孔必须是封闭圆孔或封闭长圆孔，不采用开口式 C 形槽
- 不依赖 3D 打印螺纹承力，螺丝直接穿过转接板和支架臂板，锁入显示器原有的金属螺纹座
- 转接板增加 6 mm 后，原支架螺丝可能不够长；应准备 M4 加长螺丝和垫圈，禁止螺丝顶到显示器螺纹孔底部

## 每个挂灯型号只需记录

### 1. 底座宽度

在正常夹持姿态下，测量原装底座左右两侧最外轮廓的宽度。

- 符号：`base_width`
- 用途：决定两条防横移挡肩的内间距
- 默认单边装配间隙：约 `0.5 mm`

### 2. 卡扣前后夹持深度

测量原装底座前后卡扣能够有效夹住“显示器上沿”的前后厚度。

- 符号：`clamp_depth`
- 用途：决定承托片前后长度
- 承托片应略小于最大夹持开口，通常预留约 `2–4 mm` 的弹簧压紧余量
- 对小米 1S，当前设计值取 `30 mm`

### 3. 可选检查项

以下项目不是每个型号都必须用卡尺测量，只在结构明显特殊时记录：

- 有效夹持高度：默认按 `14 mm` 设计；若原装卡扣有效咬合高度明显小于 10 mm，需要单独记录
- 底座下方最低点：用于确认旋转或俯仰时不会撞击承托臂
- USB-C 接口方向：仅用于安装和走线说明
- 侧面包边避让：普通底座默认只做浅包边，高度约 `3–5 mm`

## 测量方法

1. 原装底座保持完整，不要拆卸。
2. 按实际工作姿态摆放：顶部横条水平，前压条和后弧形压脚向下。
3. 用游标卡尺量左右最外轮廓，得到 `base_width`。
4. 量前卡扣到后压脚之间能够稳定夹住的最大前后厚度，得到 `clamp_depth`。
5. 不要用底座整体占地尺寸代替卡扣开口尺寸。
6. 不要把显示器厚度、包装尺寸或底座旋转后的包络尺寸填入这两个字段。

## 承托片首件验证

1. 只打印承托片试片，不打印完整 VESA 支架。
2. 检查前卡扣和后压脚是否都落在承托片外侧。
3. 装上灯体后轻推中心，底座不应左右晃动或绕竖轴自由转动。
4. 调整俯仰和旋转时，包边不能碰到原装夹具的活动结构。
5. 若卡扣盖在承托片上面，缩短前后深度；若夹持太松，逐步增加深度并保留弹簧压紧余量。

## 打印前门槛

每个挂灯型号只需要完成：

- `lamp_model`
- `base_width`
- `clamp_depth`

只有在结构特殊或试片出现干涉时，才需要补充可选检查项。
